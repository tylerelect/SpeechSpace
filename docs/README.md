# SpeechSpace website

A one-page marketing site for [SpeechSpace](https://github.com/tylerelect/SpeechSpace), the voice journal that lets kids describe their favorite moment and helps parents keep those memories.

It's plain HTML and CSS in a single `index.html`, plus app screenshots in `img/`. There's no build step.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

## Publish with GitHub Pages

1. Go to **Settings → Pages** in this repo.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the `main` branch and the `/ (root)` folder, then save.

The site will be live at `https://tylerelect.github.io/speechspace-site/` within a minute or two.
